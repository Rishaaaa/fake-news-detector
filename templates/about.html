About this project

A machine learning system that classifies news text as FAKE or REAL using natural language processing and supervised classification.

Abstract

The rapid spread of misinformation through online platforms has made the automatic detection of misleading news an important research problem. This project implements an end-to-end fake news detection system that applies natural language processing to clean and normalise raw news text, converts it into numerical features using TF-IDF vectorization, and classifies it with supervised machine learning algorithms.

Four classifiers — Logistic Regression, Multinomial Naive Bayes, Linear Support Vector Machine and Random Forest — are trained and compared on a labelled news dataset. The best performing model is selected using cross-validation and deployed behind a Flask web application that provides both an interactive interface and a JSON API.

How the system works

  1. Text preprocessing. Input is lowercased; URLs, HTML tags, punctuation and digits are removed; the text is tokenized; English stopwords are dropped; and each remaining word is lemmatized to its dictionary form.
  2. Feature extraction. TF-IDF converts the cleaned text into a numeric vector. Terms that are frequent in one document but rare across the corpus receive the highest weights, because those are the terms that best distinguish one document from another.
  3. Classification. The trained model scores the vector and outputs a class together with a probability.
  4. Explanation. For linear models, each term's TF-IDF value is multiplied by its learned weight to show which words drove the decision.

Limitations

Understanding what this system cannot do matters as much as its accuracy.

  • It does not check facts. The model recognises writing style and vocabulary patterns. It has no knowledge base and cannot verify whether an event actually happened.
  • It is bound to its training data. The dataset covers a particular period and set of topics, largely US political news. Accuracy on current events, other countries or other domains will be lower.
  • Topic words can be mistaken for style. If certain names or subjects appear mostly in one class in the training data, the model may learn the topic rather than the deception.
  • English only. The stopword list and lemmatizer are English.
  • Short text is unreliable. A headline leaves few tokens after preprocessing, so the model has little to work with.
  • It can be evaded. Someone who knows the model can write around its learned patterns.
